The Flagship · Privacy & Systems

Velora OS

IN ACTIVE DEVELOPMENT · v49-rel39

Lingkungan desktop Linux Debian (ARM64) mandiri dan brankas berkas terenkripsi dalam satu APK Android tanpa akses root (Zero-Root). Dilengkapi X11 server bawaan, desktop shell Rust kustom, manajer berkas, dan pembaruan OTA.

• Core & Runtime: Rootfs Debian 13 (Trixie ARM64) di ruang pengguna Android via PRoot dan X11 server libXlorie.so (kompatibel Android 8.0+ ARM64 & 16 KB page-size).
• Desktop Shell: Compositor & window manager Rust mandiri (x11rb + tiny-skia + fontdue) dengan File Manager, minimize/maximize/resize jendela, Taskbar, pengaturan resolusi layar, dan 10 bahasa UI.
• Encrypted Vault: Brankas AES-256-GCM (chunk 64 KiB), derivasi kunci Argon2id, sub-kunci per-berkas HKDF-SHA256, indeks nama file terenkripsi, dan pembersihan kunci RAM (zeroize) saat terkunci.

NEW PROJECT
Qwen3.5-9B Shrunk + Extra Engine

Bedah biner GGUF dan mesin penalaran lokal 100% CPU-only (0 GPU, RAM 7.6 GiB) untuk model Qwen3.5-9B Uncensored — memangkas ukuran model dari 4.60 GiB → 3.49 GiB tanpa merusak 32 layer berpikirnya, sekaligus mendongkrak akurasi coding Python dari 0% polos → 90.0% (27/30 soal).

• Selective GGUF Surgery: Kompresi khusus tensor output.weight (BF16 1940 MiB → Q6_K 795.7 MiB) lewat libggml-base.so; 426 tensor lain & 66 metadata disalin utuh bit-demi-bit (hemat 1.12 GiB).
• Extra Engine v3 Verifier: Mematikan loop <think>, instrumentasi ast assert, deteksi infinite loop baris eksak (signal.alarm), pola invarian non-bocor, dan Fresh-Design Reset.
• Benchmark Jujur 30 Soal: 10/10 soal awal + 17/20 soal baru (unseen) lulus di Intel Core i5 tanpa GPU (1.25–2.35 t/s).
