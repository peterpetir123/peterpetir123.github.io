The Flagship · Privacy & Systems

Velora OS

IN ACTIVE DEVELOPMENT · v42-rel32

Lingkungan desktop Linux Debian (ARM64) mandiri dan brankas berkas terenkripsi dalam satu APK Android tanpa akses root (Zero-Root). Dilengkapi X11 server bawaan, desktop shell Rust kustom, manajer berkas, dan pembaruan OTA.

• Core & Runtime: Rootfs Debian 13 (Trixie ARM64) di ruang pengguna Android via PRoot dan X11 server libXlorie.so (kompatibel Android 8.0+ ARM64 & 16 KB page-size).
• Desktop Shell: Compositor & window manager Rust mandiri (x11rb + tiny-skia + fontdue) dengan File Manager, minimize/maximize/resize jendela, Taskbar, pengaturan resolusi layar, dan 10 bahasa UI.
• Encrypted Vault: Brankas AES-256-GCM (chunk 64 KiB), derivasi kunci Argon2id, sub-kunci per-berkas HKDF-SHA256, indeks nama file terenkripsi, dan pembersihan kunci RAM (zeroize) saat terkunci.
